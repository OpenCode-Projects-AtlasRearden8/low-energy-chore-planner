## What was built

A static PWA, installed-on-your-own-machine-style chore planner sized for low-energy (ADHD-friendly) days. Designed, written and tested fully offline-capable: no build step, no runtime dependencies, no server, no accounts, no secrets, no personal data.

Features:

- **Tiny tasks** — tasks are one-sitting small; add form nudges for tiniest version; *Make it smaller* generates a "10-minute version of ..." title; effort tiers Tiny / Small / Medium-ish (1–3 spoons); notes; archive/restore/delete.
- **Energy levels (spoons)** — user picks today's energy (1–5 spoons, changeable any time; resets naturally each day by date rollover). Each completion spends spoons; "Fits right now" narrows tasks to what remaining energy covers, with gentle copy when nothing fits or all spoons are spent.
- **Gentle, streak-free progress** — rolling 7-day win count, all-time total, and a 14-day dot strip where filled dot = win day, empty = rest day. Explicitly no streaks, guilt or shame copy anywhere.
- **"Just one thing" picker** — random suggestion weighted toward tiniest tasks (weights 3/2/1 by spoon cost), filtered to today's remaining spoons, skipping tasks already done today (with a fallback so it never stalls); actions "Done it" / "No thanks, spin again".
- **Offline storage** — state in `localStorage` (`lecp-state-v1`), hardened by a `sanitizeState` pass (drops junk rows, clamps values, caps runaway arrays, survives corrupt JSON with starter-state fallback). JSON backup export/import for data ownership.
- **Offline PWA** — service worker with versioned cache-first precache of all 11 assets, navigation fallback to `index.html`, old-cache cleanup on activate; `manifest.webmanifest` + generated PNG/SVG icons; installable on localhost/HTTPS.
- **Accessible high-contrast mode** — one-click toggle (persisted) plus auto-enable via `prefers-contrast: more`; pure-black theme with 7:1+ text contrast, strong focus outlines. Also: semantic HTML, `aria-live` announcements, visible focus rings everywhere, ≥44px touch targets, `prefers-reduced-motion` respected, all dynamic content rendered via `textContent` (no HTML injection).
- First run seeds 8 gentle sample tasks (one-click removal in Settings).

Not included by definition: cloud sync, accounts, reminders/notifications, recurring schedules. This is a life-admin helper, not medical advice.

## How to run

```sh
# serve (any static server works)
python3 -m http.server 8000
# then open http://localhost:8000
```

Tests / checks (Node 18+):

```sh
npm test      # 40 tests: core logic tests + jsdom end-to-end smoke test
npm run verify
npm run icons   # regenerate PNG icons (scripts/make-icons.js, also dependency-free)
```

## Known gaps

- The end-to-end smoke test uses jsdom, not a real browser; actual rendering/layout, service worker behavior in-browser, and PWA install prompts are verified by static analysis and standard patterns rather than real browser automation (no browser available in this environment).
- A deployed copy will keep serving the cached version until `CACHE_NAME` in `sw.js` is bumped — bump it whenever bundled assets change (documented in README).
- No automatic calendar/recurring tasks and no notification reminders — deliberate scope cut for v1.
- There is no undo for "Done it": the win history is never edited after the fact. This is by design, but worth knowing.
- Week/day display uses the device's local timezone; a device crossing timezones mid-session may see its day boundary shift slightly.
